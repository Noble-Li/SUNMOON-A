# 国内霍尔电推进招标采购日报

每日 17:00 自动更新国内霍尔电推进相关招标 / 采购 / 中标 / 成交公告。

**线上地址**：https://noble-li.github.io/SUNMOON-A/

---

## 目录结构

```
├── index.html                        # 主页面（今日详情 / 本周汇总 / 历史归档 / 跟踪项目表）
├── data/
│   └── reports.json                  # 唯一数据源，每日追加
├── 霍尔电推进日报_离线单文件版.html   # 数据内联版，双击即可查看、可单独转发
├── .nojekyll                         # 关闭 GitHub Pages 的 Jekyll 处理
└── README.md
```

## 页面结构

| 板块 | 内容 |
|---|---|
| 今日详情 | 当天新增项目（编号、采购人、中标人、金额、日期、原文链接）+ 近期关键时间节点 + 检索受限说明 |
| 本周汇总 | 最近 7 个自然日一览，标注每天有 / 无新增 |
| 历史归档 | 2025-06 起，按月分组、可展开；灰色「回填」徽标区分事件式回填与逐日跟踪 |
| 跟踪项目表 | P01~P18 完整状态，含每个项目的下一关键节点 |

## 数据格式

`data/reports.json` 顶层两个字段：

- `site`：站点信息 + `tracked_projects`（P 编号跟踪表，含 `next_milestone`）
- `reports`：日报数组，**最新的在最前面**

单条日报结构：

```json
{
  "date": "2026-10-10",
  "weekday": "星期六",
  "has_new": true,
  "summary": "一句话总结",
  "new_items": [
    {
      "id": "P01",
      "title": "项目名称",
      "buyer": "采购人",
      "winner": "中标人（无则留空）",
      "amount": "金额",
      "publish_date": "2026-10-10",
      "url": "原文链接（无则留空串）",
      "note": "备注"
    }
  ],
  "upcoming": [{ "date": "2026-10-15", "event": "事件", "detail": "说明" }],
  "constraints": "检索受限说明"
}
```

约定：

- `has_new: false` + 空 `new_items` → 页面显示「今日无新增」
- `url` 留空串 → 页面显示「无公开原文链接」
- 历史回填条目加 `"backfill": true` → 显示灰色「回填」徽标
- 新增跟踪项目时，需同步更新 `index.html` 中「P01 ~ PXX 完整状态」表头与顶部计数文案

## 历史归档口径

- **2026-10 起**：逐日跟踪记录
- **2025-06 ~ 2026-09**：事件式回填（依据《国内霍尔电推进招标采购与标书技术指标汇编 v5》，2026-09-22 编制），条目带 `"backfill": true`
  - 仅收录公开可查的关键节点，未检索到的日期不代表当日无公告
  - 归档起点：2025-06-01（该条目为归档口径说明）
  - P10（2025-04-01 公示）、P13（2019-01-29 公示）早于归档起点，仅在跟踪表中保留

## 检索说明

数据来源为中国政府采购网、各采购人官网、招标信息平台等公开渠道。中招联合招标采购平台、军队采购网等内容位于登录墙后，公开检索无法覆盖全量。
