## 自动化流程

每日 17:00 自动化任务（`automation-1791421596954`）执行：

1. **检索**：4-6 轮 Web 搜索（关键词：霍尔电推进、霍尔推力器、PPCU、空心阴极、贮箱、真空舱、空间环境模拟；重点核对 P01~P18 已跟踪项目状态）
2. **生成对话回复**：在用户会话中输出当日跟踪汇报
3. **更新 reports.json**：将当日汇报数据追加到 `data/reports.json`
4. **部署到云端**：调用 `cloudstudio-deploy` 技能重新部署静态网站
5. **回写执行记录**：更新 `automation-1791421596954/memory.md`
